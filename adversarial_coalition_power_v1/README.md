# Adversarial Coalition Power v1

## Core

**Adversarial coalition power is verified collective capacity to create distinct principal-valued outcomes under strategic interaction while preserving authority lineage, identity uniqueness, coalition stability, truthful evidence, evaluator independence, and safe exit.**

A coalition is not powerful merely because its members can coordinate. Collusion, sybil duplication, scope expansion, unstable value division, evaluator capture, unsupported claims, or inability to dissolve safely reduce admissible collective power.

## Integrated scientific boundary

This slice connects:

- robust coalition value across worlds;
- action-based collusion auditing;
- attenuated delegation and sybil-resistant authorization;
- evaluator independence and evidence provenance;
- rollback after coalition loss.
