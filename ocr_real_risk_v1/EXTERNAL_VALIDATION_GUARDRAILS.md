# External validation guardrails

1. Do not change the frozen model, threshold, views, feature extractor or acceptance rule after opening the external dataset.
2. Bind source files, model, selector and protocol by SHA-256 before OCR outcomes are observed.
3. Use one deduplicated physical numeric location per document image.
4. Count abstentions explicitly; never erase them from the coverage denominator.
5. Separate baseline natural errors, candidate natural false accepts and counterfactual false accepts.
6. Use simultaneous exact one-sided confidence bounds, not point estimates.
7. Fail closed on duplicate evidence, conflicting truth, insufficient sample size or non-replayable calculations.
8. A positive receipt-domain result does not authorize Honduras production.
