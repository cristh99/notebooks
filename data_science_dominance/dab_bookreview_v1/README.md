# DataAgentBench BookReview V1

A frozen, transparent engine for the two unseen BookReview tasks `query2` and `query3`.

It integrates PostgreSQL book metadata with SQLite reviews, parses semistructured string fields, resolves noisy cross-database identifiers, and executes deterministic analytical plans. The candidate and tests were frozen before any access to held-out queries, validators, ground truth, or official dataset values.

Promotion is strict: only `2/2` earns `+25`; `0/2` or `1/2` earns zero. Novelty has no weight. No merge, GCloud, paid compute, or post-hoc retuning is permitted.
